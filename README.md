# ASCEND · Migration Path Planning

Mock interactivo de planificación de migración (conectividad, alcance, plan por IA y autorización de pipeline).

## Archivos (repo autocontenido)

- **`migration-path-planning.html`** — Pantalla principal; ábrela en el navegador.
- **`ascend-*.css`**, **`ascend-lazy-reveal.js`**, **`Arganologo.png`**, **`icon-lightbulb.svg`** — Mismo nivel que el HTML (sin subcarpetas).
- **`subir-a-github.sh`** — Ayuda para publicar el repo (ajusta la ruta `cd` si la usas).
- Otros HTML/SVG en la raíz son referencias antiguas; no son necesarios para la pantalla homologada.

## Dependencia externa

PrimeNG 17 (CDN en el HTML); requiere internet al abrir la pantalla.

## GitHub Pages

No hay `index.html` en la raíz: la entrada del sitio es **`migration-path-planning.html`**. Tras publicar, abre `https://TU_USUARIO.github.io/NOMBRE_REPO/migration-path-planning.html` (o configura en tu host una redirección raíz → ese archivo).

En el repositorio: **Settings → Pages** → Branch **main**, carpeta **/ (root)**.
